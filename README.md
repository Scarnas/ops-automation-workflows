# n8n Automation Workflows

Production automation workflows for small-business operations — inventory,
purchasing, fulfilment and lead handling — built in [n8n](https://n8n.io),
orchestrating Google Sheets, Gmail, Slack and external APIs.

Each `.json` is an importable workflow export. Captured execution data and
credential IDs have been stripped; workflows reference credentials by name only.

See **[WORKFLOWS.md](./WORKFLOWS.md)** for a description of each workflow.
